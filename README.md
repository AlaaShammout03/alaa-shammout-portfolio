# Alaa Shammout Portfolio

Personal portfolio showcasing full-stack, embedded, and AI projects, built from React and Spring Boot to FreeRTOS on bare ESP32 hardware.

## Stack

Next.js (App Router), TypeScript, Tailwind CSS v4, deployed on Vercel.

## Live site

https://alaa-shammout-portfolio.vercel.app

## Running locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
